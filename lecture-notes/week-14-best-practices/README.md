# Week 14: Best Practices in Infrastructure Automation

## 🎯 Learning Objectives

- Identify best practices for writing modular, testable, and well-documented IaC.
- Explain GitOps principles and their relationship to automated infrastructure delivery.
- Synthesize best practices across scripting, configuration management, orchestration, and security into a coherent approach.
- Produce a written set of automation best-practice guidelines for a given scenario.

## 🛠️ Hour 3 - Assignment: Writing Automation Best-Practice Guidelines

### Task

Students are given a short scenario describing a mid-sized organization with multiple teams, inconsistent tool usage, and a recent incident caused by an un-reviewed manual infrastructure change.

Students individually (or in pairs) draft a concise best-practices document for this organization, covering: version control and code review policy, testing/linting requirements, secrets-management policy (Week 12), CI/CD gating requirements (Week 11), and a recommendation on GitOps adoption where relevant.

Students must justify each recommended practice by referencing the specific risk or incident type it addresses, rather than listing generic advice, reinforcing CLO-3 evaluative and design skills.

Submitted documents are peer-reviewed in pairs against a short rubric (clarity, specificity, and justification) before final submission to the instructor.

### ✅ Solution

This week's task is a discussion / written / presentation activity, so there is no code to run. Prepare your answer using the task description above.

- Argo CD or Flux (open source, conceptual)
