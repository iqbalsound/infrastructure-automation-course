## 🛠️ Hour 3 - Midterm Examination (Theory + Lab)

### Task

Administer the midterm examination consisting of a theory component (covering CLO-1 concepts: definitions, principles, comparisons) and a lab/practical component (covering CLO-2 skills: writing or correcting a short script, playbook, or IaC configuration).

Theory component format: short-answer and scenario-based questions requiring explanation and justification rather than pure recall, consistent with the assessment style used throughout the course.

Lab component format: a hands-on task performed in the same lab environment used throughout the semester (Bash/Python, Ansible with Vagrant, or Terraform/OpenTofu with the local/Docker provider), assessed for correctness and, where relevant, idempotency.

Debrief logistics: submission method, time allocation per component, and permitted reference materials as specified by the instructor.

### ✅ Solution

This week's task is a discussion / written / presentation activity, so there is no code to run. Prepare your answer using the task description above.
