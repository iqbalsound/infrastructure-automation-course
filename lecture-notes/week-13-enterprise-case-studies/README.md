# Week 13: Enterprise Automation Case Studies

## 🎯 Learning Objectives

- Analyze real-world (anonymized/generalized) narratives of enterprise infrastructure automation adoption.
- Identify the business and technical drivers behind large-scale automation transformations.
- Evaluate the trade-offs and risks encountered during enterprise automation initiatives.
- Present a structured group analysis of an automation case study.

## 🛠️ Hour 3 - Group Presentations and Discussion

### Task

Each group presents their case-study analysis (approximately 8-10 minutes) covering the initial state, drivers, tools adopted, challenges, outcomes, and their own critical evaluation/recommendation.

Facilitate structured peer questioning after each presentation, encouraging groups to challenge each other's assumptions and proposed alternatives using specific course concepts.

Instructor provides feedback connecting each group's analysis explicitly to CLO-3 evaluative skills: assessing trade-offs, and aligning automation strategy with organizational context.

Close with a synthesis discussion: what common threads emerged across the different case studies, and how these threads connect to the best-practices topic scheduled for Week 14.

### ✅ Solution

This week's task is a discussion / written / presentation activity, so there is no code to run. Prepare your answer using the task description above.
